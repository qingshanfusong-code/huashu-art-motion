# 为什么年纪越大，一年过得越快

竖屏 1080×1920、30fps、约 87.6 秒的口播知识短片。画面全部用代码画，口播用开源 TTS 合成，配乐和音效也由代码合成，整条片子可以一键重渲。

- 画法：主体是 Kurzgesagt 式深靛紫底配发光强调色（`references/动画语法/y1_kurzgesagt.md`）；比例理论那段借 3b1b 的形变，让一个饼一直变，中途不切（t1）；三件小事那段借动态文字的清单写法（y5）。
- 颜色就是概念：暖黄代表新鲜的记忆画面，灰紫代表重复的日子，青色代表大脑和时间，品红只用在「假期悖论」。
- 贯穿全片的物件是一卷「记忆胶片」：童年的胶片密密麻麻，长大后的一年被压成一张。签名转场 `ffFrame` 让新镜头从一格画框里长出来。
- 全片记忆点在镜 9。365 张一模一样的日历卡越摞越高，「合并成」时先往上一提，到「一帧」那个字时用 0.12 秒拍成一张：同时闪白、震屏、扬起尘土、盖上「×1」章，配乐全停约 1 秒，只剩撞击的余响。

## 发布

- **封面**：`build/封面.png`，封面字是「为什么长大后，一年越来越短？」，配图左边是童年的长胶片，右边只剩一张灰卡。所有字都在 3:4 安全区（y 240–1680）里，信息流裁成 3:4 也不会切字。
- **标题**：为什么长大后，一年越来越短？
- **简介**（可直接用）：小时候一个暑假像过了一辈子，现在一年眨眼就没了。科学家给过两种主流解释：比例理论和记忆密度。时间变快不是命运，是你很久没有「新的一天」了。
- **评论区置顶**：你觉得人生中哪一年过得最慢？（这类问题容易让人写自己的故事；可以先写一条自己的回答带头）
- **标签**：#vibe知识 #心理学 #时间
- **防较真的背景资料**（被问到时用）：
  - 比例理论常追溯到法国哲学家 Paul Janet（1877）。
  - 「假期悖论」（holiday paradox）这个说法出自 Claudia Hammond 的《Time Warped》（2012）。
  - 用回忆里事件的多少解释时长感，是记忆与时间知觉研究里的主流思路之一。
  - 学界对「年纪越大时间越快」没有唯一定论，所以文案只写「科学家认为」。

## 重新生成

```sh
cd scripts/engine/films/why_time_flies
# 1) 口播：Kokoro v1.1-zh（Apache-2.0）。模型来自 k2-fsa/sherpa-onnx 的 GitHub release「tts-models」下的 kokoro-multi-lang-v1_1

# 2) 回听＋逐字对时：SenseVoice（release「asr-models」下的 sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17）
uv run tools/align.py --asr <sense-voice 目录>          # 打印每句字错率，并改写 timing.js
# 3) 配乐、音效、混音（−14 LUFS）
uv run tools/music.py
# 4) 画面（在 scripts/engine 下）
cd ../..
uv run --with playwright python render.py --film films/why_time_flies --fps 30 --out films/why_time_flies/build/成片.mp4 --audio films/why_time_flies/build/mix.wav
uv run --with playwright python render.py --film films/why_time_flies --solo cover --stills 0.5 --out films/why_time_flies/build/封面
# 验收（在 skill 根目录；竖屏字幕带上沿约 1400/1920）
uv run scripts/qa.py --project scripts/engine --film films/why_time_flies --sub-band 0.73 --out scripts/engine/films/why_time_flies/build/qa
```

- **换成自己的声音**：照 `script.json` 录一遍，存成 `build/vo.wav`，每句之间的停顿大致照 `gap`。然后跑 `align.py`（会按你的录音重写每句、每个字的时间）和 `music.py`，再渲一遍。只要句子顺序不变，画面会自动跟上你的语速。注意：`align.py` 按 `timing.json` 里每句的起止切音频，录音节奏和 TTS 差得多时，要先把 `tts.py` 里的切句换成按静音切。
- **改文案**：只改 `script.json`。`say` 是给 TTS 读的（数字写成汉字），`sub` 是字幕。多音字读错就在 `tools/tts.py` 的 `OVERRIDES` 里补读音。本片补过的有：「多长」「特别长」「变长」的「长」读 cháng，「一」的变调，「过得」的「得」读轻声。
- **读音验收**：`align.py` 回听本片口播，字错率 0.8%（3/370）。剩下的 3 处是同音字（它们/他们、帧/针），外加一处「变快了」被听成「变快乐」。
- 时间全部挂在口播的字上（`F.cue('L16', '一帧')`）。换文案或换声音之后，镜头边界和动作会一起跟着移，不用手改秒数。
